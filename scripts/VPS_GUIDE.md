# 🖥️ คู่มือการติดตั้งระบบแจ้งเตือน Telegram บน VPS (Primary Runner)
## โครงสร้าง 2 ชั้น: VPS (เครื่องหลัก ตรงเวลาเป๊ะ 100%) + GitHub Actions (เครื่องสำรองอัตโนมัติ)

ระบบนี้ออกแบบมาเพื่อแก้ปัญหาความหน่วงของคิว GitHub Actions โดยใช้ **VPS ของคุณเองเป็นตัวส่งหลัก** ที่มีความแม่นยำระดับวินาที (0s Delay) และคง **GitHub Actions ไว้เป็นตัวสำรอง** กรณีที่ VPS มีปัญหาหรือไฟดับ โดยมีระบบ **Deduplication Engine ผ่าน Cloudflare D1** เพื่อป้องกันไม่ให้ส่งข้อความซ้ำกันเด็ดขาด

### 🚀 ขั้นตอนการติดตั้งบน VPS (เพียง 3 ขั้นตอน)

#### ขั้นตอนที่ 1: ดึงโค้ดโปรเจกต์ลง VPS
เข้าสู่ระบบ Terminal ของ VPS (ผ่าน SSH) แล้วรันคำสั่ง:
```bash
git clone https://github.com/pattarawin2737-gif/onicorn-trade.git
cd onicorn-trade
```
*(หรือหากมีโฟลเดอร์อยู่แล้ว ให้รัน `git pull origin main`)*

#### ขั้นตอนที่ 2: รันสคริปต์ติดตั้งระบบอัตโนมัติ (1 คำสั่ง)
```bash
sudo bash scripts/vps_setup.sh
```
สคริปต์นี้จะทำให้อัตโนมัติ:
- ตั้งค่า Timezone ของ VPS ให้เป็น `Asia/Bangkok` (เวลาไทย)
- ติดตั้ง Python 3, venv, pip
- ติดตั้ง Playwright และเบราว์เซอร์ Chromium สำหรับแคปเจอร์กราฟน้ำมัน WTI

#### ขั้นตอนที่ 3: ทดสอบการส่งข้อความ
ทดสอบว่าระบบสามารถดึงการตั้งค่าจากเว็บและส่งเข้า Telegram ได้จริง:
```bash
./scripts/run_vps_alert.sh test
```
หากตั้งค่า Telegram Bot Token และ Chat ID ไว้ในหน้าเว็บแล้ว จะมีข้อความทดสอบส่งเข้าไปที่ Telegram ทันที

### ⏰ การตั้งเวลาอัตโนมัติ (เลือกวิธีใดวิธีหนึ่ง)

#### วิธีที่ 1: ตั้งค่าผ่าน Linux Crontab (แนะนำ - ไม่กินแรม เครื่องเสถียรสุด)
พิมพ์คำสั่ง:
```bash
crontab -e
```
แล้วคัดลอกข้อความด้านล่างนี้ไปวางท้ายไฟล์ (แก้ `/root/onicorn-trade` ให้เป็น path จริงบน VPS):

```cron
CRON_TZ=Asia/Bangkok

# 1. รอบเช้า 07:45 น. (จันทร์ - ศุกร์): ข่าวทองคำ, หุ้นไทยเด่น, Sector Rotation
45 7 * * 1-5 /bin/bash /root/onicorn-trade/scripts/run_vps_alert.sh morning >> /var/log/onicorn_alerts.log 2>&1

# 2. กราฟสดน้ำมัน WTI 08:00 น. (ทุกวันอังคาร)
0 8 * * 2 /bin/bash /root/onicorn-trade/scripts/run_vps_alert.sh oil_chart >> /var/log/onicorn_alerts.log 2>&1

# 3. หุ้นทะลุกรอบ 14:35 น. (จันทร์ - ศุกร์)
35 14 * * 1-5 /bin/bash /root/onicorn-trade/scripts/run_vps_alert.sh intraday >> /var/log/onicorn_alerts.log 2>&1

# 4. สรุปตลาดสิ้นวัน 17:20 น. (จันทร์ - ศุกร์)
20 17 * * 1-5 /bin/bash /root/onicorn-trade/scripts/run_vps_alert.sh market_wrap >> /var/log/onicorn_alerts.log 2>&1
```

#### วิธีที่ 2: รันเป็น Background Service ผ่าน PM2 (ไม่ต้องแตะ Crontab)
หากเซิร์ฟเวอร์มี `pm2` อยู่แล้ว สามารถสั่งรัน Daemon ได้ทันที:
```bash
pm2 start scripts/vps_daemon.py --name "onicorn-alerts" --interpreter python3
pm2 save
```
ตัวสคริปต์ `vps_daemon.py` จะคอยเช็คเวลาประเทศไทยแบบ Real-time ตลอด 24/7 และส่งข้อความตรงตามเวลาเป๊ะ

### 🛡️ ระบบป้องกันความผิดพลาดในตัว (Built-in Safeguards)

1. **Deduplication Engine (ป้องกันการส่งซ้ำ)**:
   - เมื่อ VPS ส่งข้อความรอบใดไปแล้ว จะบันทึกสถานะไปที่ Cloudflare D1 ทันที
   - เมื่อ GitHub Actions ตื่นขึ้นมาทีหลัง จะตรวจพบว่า VPS ส่งไปแล้ว และจะ **Skip** ทันที ไม่ส่งซ้ำเด็ดขาด
2. **Failover (สำรองอัตโนมัติ)**:
   - หาก VPS ดับ หรือไฟดับ หรือเน็ตหลุด ตัว GitHub Actions จะตรวจพบว่ายังไม่มีใครส่ง และจะส่งข้อความสำรองให้ทันที
3. **Stale Run Guard (ป้องกันการส่งผิดเวลา)**:
   - รอบเช้า: หากเลย 10:00 น. จะไม่ส่ง
   - รอบบ่าย (Intraday): หากเลย 16:30 น. จะไม่ส่ง
   - รอบเย็น (Market Wrap): หากเลย 19:30 น. (เช่น เที่ยงคืน) จะตัดทิ้งทันที
